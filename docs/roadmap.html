Roadmap

askbot has been around long enough to have a history — it started on SourceForge before moving here. The short version of the plan: a new version is in the works, and the board's job stays the same. What follows is honest about which parts are underway and which are ideas.

In progress next version

The next version of askbot is being worked on right now. The scope is decided by the work itself — follow the commits for the truth — but the themes on the table are the obvious ones for a codebase with SourceForge-era roots:

  • Compatibility with current PHP releases
  • A security-review pass over input handling and authentication
  • A smoother installer and clearer configuration

Ideas not promises

  • A Docker image, so a board is one docker run away
  • A REST API for reading and asking programmatically
  • A richer answer editor
  • Email notifications for answers on your questions
  • More locales beyond de_DE and en_US — the frontend.pot template is ready for them
  • A test suite and CI on GitHub Actions

Shipped

  • 2026 — Relicensed under AGPL-3.0, project site launched, default branch moved to main
  • 2023 — Repository restructured: everything moved into src/, jQuery updated
  • 2016 — Moved from SourceForge to GitHub (last SourceForge revision: R172), installer fixes
  • Before that — The SourceForge years: questions, answers, comments, tags, karma, badges, skins, locales, plugins
